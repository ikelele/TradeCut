# TradeCut

Режет видео твоих сделок автоматически. Ты торгуешь как обычно — программа
следит за журналом торгового терминала, при закрытии сделки просит OBS
сохранить буфер повтора и вырезает оттуда ровно твою сделку: от входа до
выхода, с запасом по краям.

Работает фоном, значком в трее, без окна консоли. Windows, один файл, ничего
доустанавливать не нужно.

---

## Установка

Скачай последнюю версию со [страницы релизов](https://github.com/ikelele/TradeCut/releases):

- **TradeCut-Setup-x.y.z.exe** — обычный установщик: ярлыки, удаление через
  «Установка и удаление программ», обновляется сам.
- **TradeCut-x.y.z-portable.exe** — один файл без установки. Настройки лежат
  рядом с ним, обновлять нужно вручную.

Программа **не подписана сертификатом**, поэтому при первом запуске Windows
покажет «Система Windows защитила ваш компьютер». Нажми «Подробнее» →
«Выполнить в любом случае». Сертификат подписи стоит денег и для бесплатной
программы не окупается; исходники здесь целиком, их можно проверить и собрать
самому.

## Быстрый старт

1. **Включи WebSocket в OBS**: Инструменты → Настройки сервера WebSocket →
   «Включить сервер», нажми «Показать пароль» и скопируй его.
2. **Включи буфер повтора в OBS**: Настройки → Вывод → «Включить буфер
   повтора». Длину поставь с запасом, минут пять.
3. **Запусти TradeCut.** При первом запуске откроется помощник: пароль от OBS,
   выбор терминала, разметка областей кадра. Каждый шаг проверяется прямо в
   нём — сразу видно, подключается ли OBS и находится ли журнал терминала.
4. Готово. Значок в трее зеленеет — всё работает.

Помощника можно пропустить и вернуться к нему позже: кнопка «?» в настройках →
«Пройти первую настройку».

Значок в трее показывает состояние: зелёный — работает, жёлтый — нет связи с
OBS, красный — OBS подключён, но буфер повтора выключен, серый — на паузе.

Подробности — кнопка «?» в окне настроек.

## Что умеет

- **Клипы сделок.** По каждой закрытой сделке — файл вида
  `DEEPUSDT SHORT Binance 2026-09-18 12-38-23.mp4`, в папке сегодняшнего дня.
- **Серия сделок одним клипом.** Несколько сделок подряд по одной монете
  склеиваются в общий клип — от входа в первую до выхода из последней.
- **Обрезка кадра.** На экране обычно несколько стаканов рядом, а для разбора
  нужен один. Программа находит границы панелей прямо в кадре — выделил один
  раз, дальше режется в два клика из меню трея.
- **Ускорение, обрезка по времени, без звука** — в том же окне обрезки.
- **Повтор по требованию.** «Сохранить повтор» в трее забирает последние
  15 секунд / минуту / сколько скажешь — безо всякой сделки.

## Поддерживаемые терминалы

| | Vataga | TigerTrade |
|---|---|---|
| Файлы журнала | `log-ГГГГММДД.clef` | `WorkLog_*.log` |
| Путь по умолчанию | `%APPDATA%\Vataga\Vataga.terminal\Logs` | `%APPDATA%\TigerTrade` |
| Время в журнале | UTC | локальное |

Терминал выбирается в настройках. Папку журнала указывать не нужно — она
находится сама.

## Настройка областей кадра

Разовая настройка под свой монитор — никаких «шести частей от 3440 пикселей» в
программе не зашито. На первом запуске этим занимается помощник: он сохраняет
короткий повтор из буфера OBS (клипов-то ещё нет) и открывает его для разметки.
Вручную то же самое:

1. Окно обрезки → выбери любой свой клип → **«Выделить мышью...»**
2. Потяни верх и низ рамки так, чтобы по высоте осталось нужное.
3. **«Найти границы»** — границы панелей находятся в кадре сами. Не тот
   вариант — жми «Другой вариант».
4. **«Сохранить все области»** — колонки сохранятся как «Стакан 1», «Стакан 2»
   и так далее.

После этого в меню трея по каждой сделке появится выбор нужной области.

## Настройки

Всё правится в окне настроек. Файл `config.json` трогать не нужно; у
установленной версии он лежит в `%APPDATA%\TradeCut`, у переносимой — рядом с
exe. Клипы по умолчанию — в `Видео\TradeCut` и рядом с exe соответственно.

| Настройка | По умолчанию |
|---|---|
| Адрес OBS | `ws://127.0.0.1:4455` |
| Пароль OBS | пусто — **заполнить обязательно** |
| Терминал | TigerTrade |
| Захватить до входа / после выхода | 5 / 2 сек |
| Папка клипов | `./clips` |
| Удалять исходный буфер после нарезки | включено |
| Склеивать серию сделок | включено |
| Оставлять отдельные клипы серии | выключено |
| Резать из меню трея без звука | выключено |
| Сохранять начало долгой сделки | выключено |

## Обновления

Установленная версия проверяет обновления при запуске и, если вышло новое,
спрашивает — скачать? Загрузка идёт в фоне, установка при перезапуске.
Переносимая версия себя заменить не может, поэтому просто сообщает о новой
версии и открывает страницу загрузки.

Если обновлений нет, программа молчит: окно «у вас последняя версия» при
каждом запуске — раздражение без пользы.

## Сборка из исходников

```bash
npm install
npm test             # проверки без окон
npm run test:windows # проверка окон, нужен Electron
npm run package      # -> dist/TradeCut-Setup-x.y.z.exe и портативная версия
```

Нужен Node.js 18+. `ffmpeg` и `ffprobe` ставить не нужно: они скачиваются при
`npm install` и кладутся внутрь собранного файла.

## Как устроено

```
src/              логика, не зависящая от окон (и покрытая тестами)
  app.js          жизненный цикл: слежение, очередь задач, история клипов
  terminalLog.js  чтение журнала терминала (vatagaLog.js / tigerTradeLog.js)
  obsClient.js    связь с OBS: сохранение буфера, путь к файлу из события
  clipper.js      нарезка ffmpeg: клип сделки, серия, повтор, склейка
  stakanCrop.js   обрезка готового клипа: область, скорость, время, звук
  panelDetect.js  поиск границ панелей терминала по кадру
  cropRect.js     приведение рамки к тому, что примет ffmpeg
  config.js       чтение и запись config.json

electron/         оболочка
  main.js         точка входа, IPC, трей-режим
  tray.js         значок, статус, меню
  windows.js      окна: настройки, сделки, обрезка, справка
  renderer/       сами окна (HTML + CSS + скрипты)
```

Несколько решений, которые выглядят неочевидно, но сделаны намеренно:

- **Путь к сохранённому файлу берётся из события OBS**, а не поиском «какой
  файл новее» — иначе легко схватить файл обычной записи, лежащий рядом.
- **Буфер повтора не перезапускается автоматически**, если он выключен: тихий
  перезапуск обнулил бы буфер ровно перед сохранением.
- **Размер файла проверяется на стабильность** перед чтением — OBS сообщает о
  сохранении раньше, чем дописывает файл на диск.
- **Сделка, вышедшая за пределы буфера, не роняет нарезку** — клип обрезается
  по доступным границам, а в журнал идёт предупреждение.
- **Границы областей ищутся в полосе заголовков панелей**, а не по всей высоте
  кадра: внутри стакана полно своих вертикальных линий, и отличить их от
  настоящей границы иначе нельзя.

## Тесты

```bash
npm test
```

Прогоняет сверку связей между окнами и основным процессом, модульные тесты
(включая настоящую нарезку через ffmpeg) и проверку сохранения настроек.
Отдельно `npm run test:windows` открывает все окна и проверяет, что они
собираются и в них нет ошибок.
